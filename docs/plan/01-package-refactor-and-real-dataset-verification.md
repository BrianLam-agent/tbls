## Goal

Turn the current loose-file repository into a `pip install`-able `tbls`
package (sklearn-compatible `TBLS`, `BroadLearningSystem`, `PairwiseKCCA`,
`GraphFuzzyKCCA`) with `experiments/` training code outside the package,
release hygiene (lint, type-check, CI, PyPI metadata), and — the actual
acceptance bar — a working end-to-end training run against the real datasets
in `dataset/` on the user's machine. This is a refactor/move of already-working
code (`othercode/`), not new algorithm development.

      (`fit(X1, X2[, y])`, `transform_view1`, `transform_view2`, `transform()`);
      add `BaseEstimator` only, **not** `TransformerMixin`.
    - §15.3 — `genoptim` is a directory move + import-path fix only; its
      `TBLS`-coupled functions (`fitness.py`, `ga_optimizer.py`) are **not**
      claimed to work against the new `TBLS` and no test asserts they do.
      `ensemble/*` has no such coupling and must be fully functional.

### Step 2 — Shared modules `_kernel.py`, `_ifs.py`, `_graph.py`

Write `src/tbls/_kernel.py`:
- `rbf_kernel(X, Y=None, gamma=None)` — merge `othercode/cca.py::rbf_kernel`
  and `othercode/gfcca.py::rbf_kernel` (identical bodies). Signature note:
  the original default was `gamma: float = 1.0` (gfcca) or
  `DEFAULT_KERNEL_GAMMA = 0.1` (cca) — **preserve behavior for existing
  callers** by keeping `gamma: float | None = None` meaning "use the
  caller-supplied module-level default", i.e. `cca.py`'s call sites must
  still pass `gamma=DEFAULT_KERNEL_GAMMA` explicitly; don't silently change
  cca's numeric behavior by changing the shared function's default.
- `compute_kernel_matrix(X)` — from `othercode/tbls.py::TBLS._compute_kernel_matrix`
  (adaptive-gamma variant, no `Y` argument, `gamma` always computed from the
  median heuristic — this is a distinct code path from `rbf_kernel`, keep both).
- `kernel_distance_matrix(K)` — from `othercode/tbls.py::TBLS._kernel_distance_matrix`.
- Google docstrings + full type hints on all three functions per §6.1.

Write `src/tbls/_ifs.py`:
- `compute_if_scores_geib(X, y, K=None, if_sigma=1.0)` — body of
  `othercode/tbls.py::TBLS._compute_if_scores`, with `self._compute_kernel_matrix`
  / `self._kernel_distance_matrix` calls replaced by
  `_kernel.compute_kernel_matrix` / `_kernel.kernel_distance_matrix`.
- `compute_if_scores_simple(A, y, sigma_if=1.0, delta_if=0.5, min_weight=1e-4)`
  — body of `othercode/gfcca.py::GraphFuzzyKCCA._compute_if_scores`.

Write `src/tbls/_graph.py`:
- `build_graph_laplacian(X, y, K=None, graph_alpha_in=1.0, graph_alpha_p=1.0,
  graph_knn=10, use_kernel=True)` — body of
  `othercode/tbls.py::TBLS._build_graph_laplacian`, kernel calls redirected
  to `_kernel`.
